## Qu’est-ce qui distingue WordPress d’un site sur mesure ?

WordPress est un système de gestion de contenu écrit en PHP : un thème pour l’apparence, des extensions pour les fonctions, une interface d’administration pour les pages. Selon [W3Techs](https://w3techs.com/technologies/details/cm-wordpress), relevé le 2 octobre 2026, il fait tourner 40,2 % des sites du web. Cette popularité vous donne un vaste choix de thèmes, d’extensions et de prestataires.

Un site sur mesure part d’une page blanche. Avec Next.js, l’outil que j’emploie, les pages sont produites à l’avance et servies telles quelles : le visiteur reçoit du HTML prêt à afficher, sans base de données interrogée à chaque visite. Le code ne contient que ce dont votre site se sert, et le design part de votre entreprise au lieu d’un thème partagé avec d’autres.

| Critère | WordPress | Site sur mesure |
| --- | --- | --- |
| Modifier un texte soi-même | Simple, depuis l’administration | Passe par le développeur, sauf interface d’édition prévue au devis |
| Apparence | Un thème, plus ou moins adapté | Dessinée pour votre entreprise |
| Fonctions | Une extension par besoin | Développées pour votre besoin |
| Entretien | Cœur, thème et extensions à mettre à jour | Peu de dépendances, mises à jour rares |
| Surface d’attaque | Administration, base de données, extensions | Pages statiques, aucune administration publique |

## Lequel est le plus rapide et le plus sûr ?

**La vitesse.** Le Web Almanac 2024 de HTTP Archive mesure, sur les visites réelles de Chrome, la part des sites qui passent les trois seuils des signaux Web essentiels de Google. Dans son [chapitre sur les CMS](https://almanac.httparchive.org/fr/2024/cms), WordPress obtient 40 %, contre 57 % pour Wix et 60 % pour Squarespace. Un WordPress bien construit, thème léger et peu d’extensions, peut être rapide ; les constructeurs de pages visuels chargent beaucoup de code pour afficher peu de chose, et c’est souvent là que le site perd son temps.

Un site sur mesure part avec un avantage de structure : il ne charge que ce que la page affiche. Je mesure sa vitesse sur mobile et sur ordinateur avant la mise en ligne, et c’est inclus. Pour chiffrer ce qu’une page lente vous fait perdre, lisez [site e-commerce lent : ce que ça coûte](/blog/site-e-commerce-lent-ce-que-ca-coute).

**La sécurité.** Patchstack a recensé 11 334 nouvelles failles dans l’écosystème WordPress en 2025, et 91 % d’entre elles touchaient des extensions, pas le cœur du logiciel ([State of WordPress Security in 2026](https://patchstack.com/whitepaper/state-of-wordpress-security-in-2026/)). Le cœur est solide ; chaque extension ajoutée élargit la surface d’attaque. Un site dont les pages sont produites à l’avance n’expose ni base de données ni page de connexion.

## Quand le site sur mesure se justifie-t-il ?

Le sur mesure se justifie quand votre site sert d’outil commercial. Vos prospects vous comparent à vos concurrents avant d’appeler, et un thème partagé avec eux ne vous aide pas à vous distinguer. Un artisan est dans ce cas : le client qui hésite va voir les réalisations avant de décrocher, et la page [site internet pour artisans](/services/site-vitrine/artisans) détaille ce que ce site doit montrer.

Il se justifie aussi quand le design doit raconter quelque chose qu’aucun thème ne prévoit. Pour [NSLysium](/realisations/nslysium), un projet d’école, j’ai conçu une page produit où l’objet tourne en 3D temps réel et où une journée se raconte au fil du défilement.

Enfin, il se justifie quand vos formulaires doivent arriver dans votre agenda ou votre CRM sans extension intermédiaire. Chez Würth France, j’ai repris le parcours de création de compte de l’eShop professionnel, numéro d’entreprise vérifié pendant la saisie et adresse tirée du registre : [−92 % d’erreurs et de sollicitations du support](/realisations/wurth-creation-de-compte), mesuré en interne. Ce niveau de contrôle sur un formulaire demande du code écrit pour lui.

## Et Wix ou Webflow ?

Wix et Squarespace conviennent pour démarrer seul avec un petit budget. Vous payez un abonnement, vous restez sur leur plateforme, et vous ne pourrez pas emporter votre site ailleurs tel quel.

Webflow se place entre les deux : un outil visuel plus libre qu’un thème, apprécié des agences, mais lui aussi par abonnement et sur sa plateforme. Le même raisonnement vaut pour une boutique, développé dans [Shopify ou site sur mesure](/blog/shopify-ou-site-sur-mesure).

## Questions fréquentes

### WordPress ou Webflow : lequel choisir ?

WordPress si vous voulez le plus grand choix d’extensions et de prestataires. Webflow si vous voulez un design libre sans gérer de mises à jour, en acceptant l’abonnement et la dépendance à la plateforme.

### Puis-je modifier mon site sur mesure moi-même ?

Les textes et les images vivent dans le code. Pour un site vitrine qui change peu, une modification de temps en temps passe par moi. Si vous publiez souvent, dites-le dès le premier appel : ce critère peut faire pencher vers WordPress.

### Next.js est-il bon pour le référencement ?

Oui. Les pages sont servies en HTML complet, lisibles par les moteurs dès la première visite, et les balises, les données structurées et le plan du site se règlent page par page. Le référencement dépend ensuite du contenu, comme sur WordPress.

### Mon site WordPress peut-il passer en sur mesure sans perdre son référencement ?

Oui, avec une migration préparée : inventaire des adresses, redirections 301 et reprise du contenu qui se classe. La méthode et les prix sont dans [refonte de site internet : prix et méthode](/blog/refonte-site-internet-pme).
